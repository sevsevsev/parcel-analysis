# Property analysis

Reproducible GIS analysis of a property made up of multiple parcels. Drop exported layers in
`data/raw/`, describe them in `config.yaml`, run one command, and every table and map regenerates.

## Quick start

```bash
pip install -r requirements.txt
python3 tests/make_sample_data.py                      # optional: synthetic demo data
PROPERTY_CONFIG=config.sample.yaml ./run_all.sh        # run on the demo
./run_all.sh                                           # run on your data (config.yaml)
```

## Adding your data

1. In ArcGIS Pro, export each layer to a GeoPackage (`.gpkg`) or shapefile in a **projected**
   coordinate system (State Plane or UTM, feet or metres). GeoPackage is preferred: one file,
   many layers, projection stored inside. Right-click layer > Data > Export Features, choose the
   `.gpkg` as output location.
2. Put the files in `data/raw/`. Keep rasters clipped to the property plus a margin and under
   about 100 MB each.
3. Edit `config.yaml`: set `crs`, point `parcels.path` at the parcel layer, set `id_field`, and
   list any overlay layers under `overlays:` with the attribute to summarise by.
4. Run `python3 scripts/01_inventory.py` to confirm every layer was read and has a CRS, then
   `./run_all.sh`.

## What the pipeline produces (in `outputs/`)

| Script | Output | What it does |
|---|---|---|
| `01_inventory.py` | `inventory.md` | Lists every layer: CRS, geometry, feature count, fields, bounds |
| `02_qa_parcels.py` | `property.gpkg`, `qa_report.md` | Repairs invalid geometry, finds overlaps, gaps, duplicate IDs; dissolves parcels into one property boundary |
| `03_measure.py` | `measurements.md`, `parcel_measurements.csv` | Acres and perimeter per parcel and total; compares to recorded acreage if available |
| `04_overlay.py` | `overlays.md`, `overlays.gpkg`, `overlay_*.csv` | Intersects each overlay layer with the property; acres and percent by class and by parcel |
| `05_maps.py` | `map_parcels.png`, `map_overlay_*.png`, `map_interactive.html` | Static maps with imagery basemap, scale bar, north arrow; interactive web map with toggleable layers |

`property.gpkg` and `overlays.gpkg` can be opened directly in ArcGIS Pro to check results or
to build a print layout.

## Layout

```
config.yaml           project settings (CRS, layers, fields, QA tolerances, map style)
config.sample.yaml    settings for the synthetic demo
data/raw/             your exported layers (see data/raw/README.md)
data/sample/          synthetic demo data (generated by tests/make_sample_data.py)
scripts/              numbered pipeline steps; _common.py holds shared helpers
outputs/              generated tables, GeoPackages and maps
run_all.sh            runs the steps in order
```

## Notes

- All areas are computed from geometry in the project CRS and converted to acres. A CRS in
  degrees (WGS84) is rejected; reproject first.
- Overlap and gap tolerances in `config.yaml` filter out sub-10 sq ft slivers from digitising noise.
- Basemaps are fetched from Esri tile services and need network access. Set `maps.basemap: false`
  to draw without one.
